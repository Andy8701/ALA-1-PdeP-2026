Parte A — JavaScript y el paradigma de programación estructurada

1. Generalización simbólica: ¿Cuáles son las reglas escritas del lenguaje?

JavaScript tiene una sintaxis que establece cómo se deben escribir correctamente las instrucciones de un programa. Dentro de la programación estructurada podemos encontrar elementos como variables, expresiones, asignaciones, condicionales, ciclos y funciones.

Las funciones son especialmente importantes porque permiten dividir un programa en partes más pequeñas que realizan tareas específicas. De esta manera, un problema puede organizarse mediante diferentes procesos o subalgoritmos.

Por ejemplo:

function sumar(a, b) {
    return a + b;
}

let resultado = sumar(5, 3);
console.log(resultado);

En este caso, function, los paréntesis, las llaves y return forman parte de las reglas sintácticas de JavaScript.

Además de la sintaxis, el lenguaje tiene una semántica, es decir, cada instrucción tiene un significado determinado. Por ejemplo, return a + b indica que la función debe devolver el resultado de sumar a y b.

2. Creencias de los profesionales: ¿Qué características particulares del lenguaje se cree que sean "mejores" que en otros lenguajes?

Una característica importante de JavaScript es su versatilidad, ya que puede utilizarse tanto dentro de un navegador como fuera de él mediante Node.js. Esto permite utilizar el mismo lenguaje para diferentes partes de una aplicación.

También se destaca la importancia de las funciones, que permiten organizar y reutilizar código. En JavaScript las funciones son especialmente flexibles porque también son consideradas un tipo de dato.

Desde el punto de vista de la programación estructurada, considero que una de sus ventajas es que podemos dividir un problema grande en diferentes funciones y resolver cada parte por separado. Esto hace que el código sea más fácil de organizar y reutilizar.

Parte B — Elección de JavaScript

1. ¿Tiene una sintaxis y una semántica bien definida? ¿Existe documentación oficial?

Sí. JavaScript tiene reglas sintácticas y semánticas que determinan cómo escribir y cómo ejecutar sus instrucciones.

Además, existe documentación sobre el lenguaje y sus características. En el material también se muestran diferentes formas de utilizar JavaScript, tanto en el navegador como mediante Node.js.

2. ¿Es posible comprobar el código producido en ese lenguaje?

Sí. El código JavaScript puede ejecutarse y probarse para comprobar si produce los resultados esperados.

Por ejemplo, podemos utilizar la consola del navegador para ejecutar instrucciones y observar sus resultados. El material explica que desde la consola se pueden escribir instrucciones JavaScript y ejecutarlas directamente.

También podemos probar las diferentes funciones de un programa por separado para comprobar que funcionen correctamente.

3. ¿Es confiable?

Sí, aunque depende de cómo se utilice. JavaScript permite desarrollar programas complejos y cuenta con mecanismos para detectar y manejar errores.

Sin embargo, que un programa sea confiable no depende solamente del lenguaje. También depende de que el código esté bien diseñado, probado y organizado.

Por ejemplo, si una función recibe datos incorrectos y el programa no contempla esa posibilidad, puede producirse un error durante la ejecución.

4. ¿Es ortogonal?

JavaScript tiene cierto grado de ortogonalidad, ya que muchas de sus características pueden combinarse entre sí.

Por ejemplo, podemos utilizar funciones con diferentes tipos de datos y pasar funciones como valores. Esto muestra la flexibilidad que tiene el lenguaje.

Sin embargo, no se puede decir que JavaScript sea completamente ortogonal, ya que posee diferentes reglas y comportamientos que dependen del contexto. Un ejemplo es this, cuyo significado cambia según dónde se utilice: dentro de una función, un objeto, un evento o fuera de ellos.

5. ¿Cuáles son sus características de consistencia y uniformidad?

JavaScript utiliza estructuras que permiten escribir código de una forma relativamente uniforme. Por ejemplo, las funciones tienen una estructura determinada y las estructuras de control siguen reglas conocidas.

La utilización de { } permite delimitar bloques de código y facilita la organización de las instrucciones.

Sin embargo, JavaScript tiene algunas particularidades que pueden resultar confusas al principio. Un ejemplo es justamente el comportamiento de this, que no siempre representa lo mismo dependiendo del contexto.

6. ¿Es extensible? ¿Hay subconjuntos de ese lenguaje?

Sí, JavaScript es extensible. Se pueden incorporar bibliotecas y herramientas que agregan nuevas funcionalidades al lenguaje.

Un ejemplo importante es Node.js, que permite utilizar JavaScript fuera del navegador y proporciona mecanismos para trabajar con archivos, redes y otras funciones del sistema operativo.

También existen diferentes herramientas construidas sobre Node.js, como React, Vue, Svelte y Angular.

En cuanto a los subconjuntos, podemos utilizar solamente una parte de las características de JavaScript. Por ejemplo, para aprender programación estructurada podemos trabajar inicialmente con variables, condiciones, ciclos y funciones, sin utilizar todas las posibilidades que ofrece el lenguaje.

7. El código producido, ¿es transportable?

Sí, en gran medida. Una de las ventajas de JavaScript es que puede ejecutarse en diferentes entornos.

Por ejemplo, un programa puede ejecutarse en diferentes navegadores que soporten JavaScript. Además, mediante Node.js podemos ejecutar JavaScript fuera del navegador.

Sin embargo, la forma en que funciona un programa puede depender del entorno en el que se ejecuta. Por eso, no siempre se puede garantizar que cualquier código funcione exactamente igual en todos los entornos.

Conclusión

JavaScript puede utilizarse dentro del paradigma de programación estructurada, principalmente mediante el uso de funciones y otros mecanismos que permiten dividir los programas en diferentes partes.

Una de sus principales ventajas es su versatilidad, ya que puede utilizarse tanto en el navegador como fuera de él mediante Node.js. También permite organizar los programas mediante funciones, que son una parte fundamental de la programación estructurada.

En mi opinión, JavaScript es un lenguaje bastante flexible para aprender programación estructurada, aunque algunas de sus características, como el funcionamiento de this, pueden resultar complicadas al principio.
